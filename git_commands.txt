GIT COMMANDS USED IN THE ASSIGNMENT

1. git config --global user.name "Your Name"
   Sets the username that will be associated with Git commits.

2. git config --global user.email "Your Email"
   Sets the email address associated with Git commits.

3. git init -b main
   Initializes a new local Git repository with the main branch.

4. git add index.html about.html
   Adds the HTML files to the staging area before committing.

5. git status
   Displays the current state of the repository, including modified, staged, and untracked files.

6. git commit -m "Initial commit: added index and about pages"
   Saves the initial project files in the Git repository.

7. git add index.html
   Adds the modified index.html file to the staging area.

8. git commit -m "Updated index.html with contact section"
   Records the changes made to the home page.

9. git branch feature
   Creates a new branch named feature.

10. git checkout feature
    Switches from the main branch to the feature branch.

11. git branch
    Displays all available branches and identifies the currently active branch.

12. git add about.html
    Adds the modified about.html file to the staging area.

13. git commit -m "Added project details to about page"
    Saves the changes made to about.html on the feature branch.

14. git checkout main
    Switches back to the main branch.

15. git merge feature
    Merges the changes from the feature branch into the main branch.

16. git log --oneline --all --graph --decorate
    Displays the commit history of all branches in a graphical format.

17. git add .gitignore
    Adds the .gitignore file to the staging area.

18. git commit -m "Added gitignore file"
    Records the .gitignore configuration in the repository.

19. git add contact.html
    Adds the contact.html file to the staging area.

20. git commit -m "Added contact page"
    Creates an additional commit containing the contact page.

21. git reset --soft HEAD~1
    Undoes the most recent commit while keeping its changes staged.

22. git remote add origin <repository-url>
    Connects the local repository to the remote GitHub repository.

23. git remote -v
    Displays the remote repository URLs configured in Git.

24. git push -u origin main
    Pushes the local main branch to GitHub and establishes upstream tracking.

25. git push -u origin feature
    Pushes the feature branch to GitHub and establishes upstream tracking.

26. git push
    Uploads subsequent local commits to the connected GitHub repository.
